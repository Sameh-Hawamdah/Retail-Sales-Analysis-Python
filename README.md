# 🛒 Retail Sales Data Analysis

## 📊 Project Overview
This project focuses on **Exploratory Data Analysis (EDA)** of a retail sales dataset using Python.  
The goal is to clean the data, analyze sales patterns, and extract meaningful insights that help understand customer behavior and sales performance.

This project is intended as a **beginner-level data analysis project**, demonstrating core data analysis skills and best practices.

---

## 🎯 Objectives
- Clean and preprocess raw sales data.
- Explore sales trends and patterns.
- Analyze customer behavior.
- Visualize insights using charts and plots.
- Practice real-world data analysis workflow.

---

## 🗂 Dataset
- Retail sales dataset
- The dataset contains retail transaction records with the following information:
  - **Transaction Details:** Transaction ID and Date.
  - **Customer Information:** Customer ID, Gender, and Age.
  - **Product Information:** Product Category.
  - **Sales Information:** Quantity, Price per Unit, and Total Amount.
  - **Calculated Revenue:** Total_Calculated.

> The dataset is used only for educational and analytical purposes.

---

## 🛠 Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## 🔎 Analysis Steps
1. Data loading and inspection.
2. Data cleaning and preprocessing:
   - Handling missing values.
   - Correcting data types.
3. Exploratory Data Analysis (EDA):
   - Sales trends over time.
   - Product performance analysis.
   - Revenue distribution.
4. Data visualization:
   - Line charts.
   - Bar charts.
   - Distribution plots.
5. Extracting insights and conclusions.

---

## 📈 Key Insights
- Identified sales trends over time.
- Highlighted best-performing product categories.
- Observed patterns in customer purchasing behavior.
- Detected variations in revenue across different periods.

> Insights are based on exploratory analysis and visual observations.
